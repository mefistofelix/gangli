Add a network

On your computer: gangli → Networks → Codes, and scan the QR with the phone's camera. Or paste the public code here.

How it works

  1. Once: on your computer, gangli → Networks → Codes, scan the QR with the phone's camera. The network is saved here.
  2. On the machine to add: gangli → This computer → Pair with your phone (or gangli pair): a QR appears.
  3. Scan it with the phone's camera: this page opens. Tap the network.
  4. The machine joins; a console of that network admits it.

This page keeps public codes only, in this browser. A public code can only make a machine ask to join; it cannot reach or control anything. A private code is refused: it never belongs on a phone. The message to the machine is encrypted with a key only its screen showed, and goes through the public pkarr relays.
